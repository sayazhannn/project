# ИИ-сериал про келин Аружан — Серия 1 «Жаңа үй» (Новый дом)

Формат по референсу: вертикальное 9:16, ~90 сек, стилизованная 3D-анимация (Pixar-подобные «куклы» с реалистичными лицами),
тёплая бежево-золотая палитра, субтитры по центру внизу (белый жирный шрифт с тёмной обводкой), в конце — плашка «2 серия скоро».

> Название сериала пока не выбрано. Варианты: «Келін», «Келін жолы» («Путь невестки»), «Тесная корона», «Жаңа үй — новая жизнь».

## Озвучка
- Язык: русский с вкраплением казахских слов (келін, шеше, әже, бата, дастархан) — как говорят в Казахстане; финальная фраза строго по-казахски, как в вашем описании.
- Субтитры: русские; казахская реплика — оригиналом + перевод мелким шрифтом.
- Голоса (ElevenLabs): Аружан — Azhar (kk, young female) или русский «Soldani» (мягкий казахский акцент); Гульмира — зрелый женский голос (Maria / Olga); Данияр — Ерсұлтан (kk male); Серик — низкий спокойный мужской голос (Bauyrzhan); Мадина — Nelli (капризная подача).

## Технический план производства (когда будет доступно видео)
1. Референсы: по одному портрету каждого героя (image model), затем ими «якорим» все кадры.
2. Кадры 1–12: image-to-video, ~6–10 сек, один непрерывный жест на клип (иначе лица «плывут»).
3. Озвучка отдельными репликами (`eleven_v4`), затем монтаж: клипы + голос + музыка + бёрнин-субтитры.
4. Финальный экспорт 1080×1920.
