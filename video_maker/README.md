# Генератор мотивационных видео (минимализм, чёрный фон, белое свечение)

Образец: `motivation_video_elevenlabs.mp4` в корне репозитория (9 сцен, ~32 сек, 1280x720, 30 fps).

Файлы:
- `audio.py` — текст озвучки (список `lines`) и озвучка голосом Piper (офлайн). Для финальной версии лучше голос ElevenLabs.
- `render.py` — рендер кадров (PIL + numpy, свечение через blur, вывод в ffmpeg). Функция `scene(i, t, c)` рисует сцену i: человечек, ступени, график, чек-лист, кнопка. Заголовки сцен — списки строк в `words_reveal(...)`.
- `mix.py` — фон (тихий дроун) и низкие удары на смене сцен.
- `Oswald.ttf` — шрифт с кириллицей.

Как собрать новое видео:
1. Написать 8–9 коротких строгих фраз (каждая — одна сцена), заменить `lines` в `audio.py`.
2. Подогнать заголовки и анимации в `scene()` под новый смысл сцен.
3. Озвучка: либо `python3 audio.py` (Piper), либо файл ElevenLabs. Для файла: найти паузы командой `ffmpeg -i voice.mp3 -af silencedetect=noise=-38dB:d=0.18 -f null -`, записать начала сцен и длительности в `scenes.json` (`starts`, `D`, `total`, `lead`), `render.py` подхватит их сам.
4. Рендер в 4 процесса: `python3 render.py <начало> <конец> partN.mp4`, склейка `ffmpeg -f concat`, добавить звук.

Зависимости: `pip install piper-tts pillow numpy`, ffmpeg. Голос Piper (RU, мужской) качать с GitHub:
`https://github.com/k2-fsa/sherpa-onnx/releases/download/tts-models/vits-piper-ru_RU-denis-medium.tar.bz2`
(huggingface и сервисы Edge TTS из облачной среды недоступны). Пути к модели в `audio.py` поправить.

Правила стиля: строгий императивный тон, никаких мягких вопросов, без тряски кадра (она выглядела как дрожь), паузы между сценами не больше ~0,5 сек.
